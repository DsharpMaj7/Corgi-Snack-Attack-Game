# Corgi-Snack-Attack-Game

A cute Pac-Man-inspired browser game where a kawaii corgi collects snacks, dodges cats, and clears snack-filled maze levels.

## Features
- 5 playable levels
- Custom corgi player 
- Enemy cat sprites
- Kawaii snack collectibles
- Lives, score, and streak celebrations
- Browser-based HTML/CSS/JavaScript game

## Status
Playable MVP. Player turning and enemy pathing are still being tuned for smoother game feel.
